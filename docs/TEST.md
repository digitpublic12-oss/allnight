## 5. 미검증·남은 위험

- 실제 배포 주소에서의 제보·로그인·관리자 동작 (배포 후 확인)
- 휴대폰 화면: 데스크톱 전용 서비스라 1024px 미만은 안내 문구만 표시 (확인함)
- 비회원 제보의 IP별 요청 제한 없음 — Turnstile에 의존
- Supabase 보안 점검 경고 7건(로그인 사용자가 관리자 함수 호출 가능)은 의도된 것: 함수 안에서 관리자 여부를 다시 확인해 거부함 (위 2-4, 2-5)
