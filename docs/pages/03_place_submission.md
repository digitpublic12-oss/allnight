# 페이지 명세: 신규 장소 제보 패널

> 경로: `/` 지도 셸 내 왼쪽 400px 패널 스택 (플로팅 '장소 제보' 메뉴로 진입)  
> 상태: [MVP] 1차 구현 대상  
> 대상 플랫폼: 데스크톱 웹  
> 레이아웃: 전면 카카오 지도 유지 + 왼쪽 400px 단일 스크롤 폼 패널

---

## 1. 페이지 목적 및 접근 권한

### 1.1 페이지 목적
- 사용자가 심야에 영업하는 새로운 장소를 플랫폼에 제보하여 데이터베이스를 확장할 수 있도록 한다.
- 비회원도 회원가입 장벽 없이 자유롭게 제보할 수 있도록 하며, 제출된 제보는 관리자의 검토 및 승인을 거쳐 공개 데이터로 편입된다.

### 1.2 접근 권한
- **모든 사용자 접근 가능 (비회원, 로그인 회원, 관리자 공통 허용)**
- 로그인하지 않은 비회원도 완전한 제보 작성이 가능하며, 비회원 연락용 이메일 입력은 선택 사항이다.

---

## 2. UI 구성과 사용자 동작

### 2.1 폼 기본 구조 (SITEMAP.md §6, DESIGN.md §9)
- **한 화면 스크롤 폼**: 단계별 마법사(Wizard) 형태를 사용하지 않고 위에서 아래로 자연스럽게 스크롤하는 단일 폼으로 구성.
- **헤더**:
  - `[< 취소]` 뒤로가기 버튼: 클릭 시 작성 취소 후 이전 지도/목록 화면으로 복귀.
  - 폼에 입력 중인 내용이 1개라도 있을 경우 **"작성 중인 내용이 사라집니다. 나가시겠습니까?" 확인 모달** 표시.
  - 타이틀: `"신규 야간 장소 제보"`.
  - 안내 문구: `"제보해주신 장소는 관리자 검토 후 등록됩니다."`

### 2.2 입력 필드 구성
1. **장소명 (필수)**:
   - 텍스트 입력창.
   - **중복 장소 방지 UI**: 장소명 입력 시 실시간/디바운스로 기존 등록 장소 중 유사한 이름의 장소 목록을 인라인 카드로 표시.
   - 유사 장소가 존재하는 경우: `"이미 등록된 장소인가요? [이 장소의 정보 수정 제보하기]" (클릭 시 해당 장소의 수정 제보 패널로 이동)` 안내. (단, 신규 제보 제출 자체를 강제로 차단하지 않음)
2. **위치 및 주소 (필수)**:
   - **주소 검색창 및 [주소 검색] 버튼**: 주소/도로명/장소명 검색 팝업 또는 자동완성을 통해 공식 주소 선택.
   - 선택 시 `도로명 주소`, `지번 주소`, `위도(latitude)`, `경도(longitude)`가 자동 바인딩.
   - 상세 주소(층, 호수 등) 추가 입력 필드.
   - *주의: 지도 임의 클릭을 통한 핀 지정 방식은 지원하지 않음 (SITEMAP.md §6 확정).*
3. **카테고리 (필수)**:
   - 8개 표준 카테고리 중 **단 1개 선택** (라디오 버튼 또는 선택 칩 형태).
   - 선택지: `음식·카페`, `쇼핑·생활`, `학습·업무`, `의료·응급`, `여가·문화`, `운동·건강`, `교통·이동`, `기타`.
4. **영업시간 입력 (필수)**:
   - **간편 편의 버튼**:
     - `[24시간·연중무휴]`: 클릭 시 월~일 7개 요일 모두 `open_24h`로 일괄 설정.
     - `[매일 동일한 시간]`: 첫 번째 요일 입력 시간을 전 요일에 일괄 복사.
   - **요일별(월~일) 스케줄 테이블**:
     - 각 요일별 상태 선택: `영업(open)` / `24시간(open_24h)` / `휴무(closed)` / `잘 모름(unknown)`.
     - `영업(open)` 선택 시: 시작 시간(`start_time`, HH:mm) 및 종료 시간(`end_time`, HH:mm) 입력.
     - 종료 시간이 자정을 넘는 경우 **[익일 체크박스]** 또는 자동 익일(`end_day_offset = 1`) 처리.
     - 브레이크타임이 있는 경우 `[+ 영업 구간 추가]`로 복수 구간 입력 가능.
5. **부가 정보 (선택)**:
   - **전화번호**: 텍스트 입력 (선택).
   - **웹사이트 / SNS URL**: 텍스트 입력 (선택).
   - **표준 편의시설/태그**: 관리자가 등록한 표준 태그 칩 다중 선택 (예: `#주차가능`, `#콘센트많음` 등. 사용자 자유 태그 입력 불허).
   - **제보 근거 및 메모**: 방문 경험, 사진 출처, 참고 링크 등 자유 메모 텍스트영역 (선택).
6. **제보자 정보 (선택)**:
   - 로그인 회원의 경우: 프로필 계정 ID 자동 연결 (별도 입력란 없음).
   - 비회원의 경우: 연락 가능한 이메일 주소 입력 필드 (선택 사항이며 필수가 아님).

### 2.3 하단 제출 영역
- **[제보 제출하기] 버튼**:
  - Primary Blue 채움 버튼 (`height 36px`).
  - 필수 항목(장소명, 주소, 카테고리, 요일별 시간)이 충족되지 않은 경우 비활성화 또는 클릭 시 미입력 항목으로 스크롤 이동 및 인라인 에러 표시.
- **제출 성공 시**:
  - 버튼 로딩 스피너 표시 후 접수 완료 패널로 전환:
    - `"제보가 성공적으로 접수되었습니다. 관리자 확인 후 서비스에 반영됩니다."`
    - **[확인 / 지도 둘러보기]** 버튼 클릭 시 기본 지도 화면으로 복귀.
    - 화면 우측 하단에 성공 토스트 노출.

## 3. DB 연동 및 API

### 3.1 호출 API
- `POST /api/submissions`
  - 요청 본문 (`jsonb` 스키마 검증):
    ```json
    {
      "type": "new_place",
      "placeId": null,
      "proposedData": {
        "name": "새벽집 카페 강남점",
        "categoryId": "uuid-category",
        "addressFull": "서울 강남구 테헤란로 123",
        "addressDetail": "지하 1층",
        "province": "서울특별시",
        "cityDistrict": "강남구",
        "latitude": 37.4981,
        "longitude": 127.0276,
        "phone": "02-123-4567",
        "websiteUrl": "https://example.com",
        "tagIds": ["uuid-tag-1"],
        "schedule": [
          { "weekday": 1, "status": "open", "intervals": [{ "start": "18:00", "end": "03:00", "endDayOffset": 1 }] },
          { "weekday": 2, "status": "open", "intervals": [{ "start": "18:00", "end": "03:00", "endDayOffset": 1 }] }
          // ... 7일
        ],
        "note": "직접 새벽 1시에 방문해서 확인했습니다."
      },
      "guestEmail": "guest@example.com"
    }
    ```

### 3.2 DB 저장 불변조건 (DB.md §3.7)
- **신규 제보는 승인 전 `places` 테이블에 절대 레코드를 생성하지 않음.**
- 오직 `submissions` 테이블에만 저장:
  - `type`: `'new_place'`
  - `place_id`: `NULL`
  - `status`: `'received'`
  - `submitted_by`: 로그인한 회원이면 `auth.uid()`, 비회원이면 `NULL`
  - `guest_email`: 비회원이 입력한 이메일 (공개 조회 불가)
- 악의적인 스팸 제보를 방지하기 위해 서버 측 Rate Limiting(요청 제한) 적용.

## 4. 예외 상태 (Error States)

### 4.1 필수값 누락 및 형식 오류
- 장소명 미입력, 주소 미선택, 카테고리 미선택, 시간 형식 오류(시작 시간과 종료 시간이 동일하거나 잘못된 경우):
  - 제출 버튼 클릭 시 해당 필드로 자동 스크롤되고 빨간색 테두리 + 에러 메시지 표시.

### 4.2 작성 중 이탈 (Dirty State Exit)
- 사용자가 한 글자라도 입력한 상태에서 [취소]를 누르거나 브라우저 뒤로가기 클릭 시:
  - `"작성 중인 내용이 저장되지 않고 사라집니다. 정말 나가시겠습니까?"` 확인 대화상자 노출.

### 4.3 서버 제출 실패
- 네트워크 단절 또는 서버 오류로 제보 접수 실패 시:
  - 입력한 폼 데이터를 그대로 유지한 채 화면 상단에 `"제보 접수 중 오류가 발생했습니다. 다시 시도해주세요."` 에러 배너 표시.

## 5. 완료 조건 (Acceptance Criteria)

1. [ ] 플로팅 메뉴의 '장소 제보' 클릭 시 왼쪽 패널이 단일 스크롤 제보 폼으로 전환된다.
2. [ ] 비회원 상태에서도 로그인 없이 제보 작성이 시작되고 정상 제출된다.
3. [ ] 장소명 입력 시 유사 장소 목록이 노출되어 중복 여부를 확인할 수 있다.
4. [ ] 주소는 검색 인터페이스를 통해서만 선택 가능하며 좌표가 정상 입력된다.
5. [ ] 7개 요일별 영업시간 및 24시간/익일 종료 옵션이 정확히 설정된다.
6. [ ] 제출된 제보는 공개 `places`에 즉시 노출되지 않고 `submissions` 테이블에 대기 상태로 저장된다.
7. [ ] 작성 중 뒤로가기 시 이탈 확인 대화상자가 표시된다.
8. [ ] 제출 완료 후 안내 메시지와 함께 원래 지도 화면으로 안전하게 복귀한다.
