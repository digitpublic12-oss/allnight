# 페이지 명세: 관리자 리뷰 관리 (`/admin/reviews`)

> 경로: `/admin/reviews`  
> 상태: [MVP] 1차 구현 대상  
> 대상 플랫폼: 데스크톱 웹  
> 레이아웃: 관리자 셸 (사이드바 + 상단 필터 + 리뷰 관리 테이블/리스트)

---

## 1. 페이지 목적 및 접근 권한

### 1.1 페이지 목적
- 일반 회원이 작성한 텍스트 리뷰 중 욕설, 비방, 스팸 홍보, 또는 이용자 신고가 접수된 부적절한 리뷰를 모니터링한다.
- 운영 원칙에 위배되는 리뷰를 숨김(블라인드) 처리하거나 소프트 삭제하여 커뮤니티 신뢰도를 유지한다.

### 1.2 접근 권한
- **관리자 전용 (`profiles.role = 'admin'`)**
- 관리자 외 접근 불가.

---

## 2. UI 구성과 사용자 동작

### 2.1 상단 검색 및 필터 바
1. **키워드 검색**: 리뷰 본문 내용, 장소명, 작성자 닉네임 검색.
2. **신고 접수 필터**: `[ ] 신고 접수된 리뷰만 보기` 체크박스 (우선 검토 필요 항목).
3. **상태 필터**: 전체 / 정상 공개 / 숨김 처리됨 / 삭제됨 드롭다운.

### 2.2 리뷰 관리 테이블
- 밀도 있는 테이블 형태로 전체 리뷰 조회:
  - **작성 일시**: `YYYY-MM-DD HH:mm`.
  - **대상 장소**: 장소명 (클릭 시 해당 장소 상세 페이지 새 탭 오픈).
  - **작성자**: 회원 닉네임.
  - **리뷰 본문**: 텍스트 본문 (긴 경우 2~3줄 말줄임, 클릭 시 전체 내용 팝업).
  - **실제 영업 여부 기록**: 리뷰 작성자가 함께 기록한 실제 영업 여부 (`open` / `closed` / 없음).
  - **상태**:
    - `공개 (Active)`: 초록 뱃지.
    - `신고 접수 (Reported)`: 앰버 뱃지 (신고 횟수 표시).
    - `숨김 (Hidden)`: 회색 뱃지 (숨김 사유 툴팁).
    - `삭제 (Deleted)`: 빨간색 뱃지.
  - **액션**:
    - **[숨김 처리]**: 리뷰를 비공개 처리하고 사유를 기록하는 모달 오픈.
    - **[숨김 해제]**: 정상 리뷰로 판단 시 숨김 해제하여 공개 상태 복구.
    - **[삭제]**: 소프트 삭제 처리.

### 2.3 숨김 처리 모달 (Hide Dialog)
- 부적절 리뷰 판정 시 [숨김 처리] 클릭:
  - 숨김 사유(`hidden_reason`) 선택/입력:
    - `욕설 및 비방`
    - `스팸 및 불법 광고`
    - `허위 사실 유포`
    - `기타 직접 입력`
  - [숨김 확정] 클릭 시:
    - DB에 `hidden_by = auth.uid()`, `hidden_reason = :reason` 저장.
    - 일반 공개 화면에서 해당 리뷰 즉시 미노출.

## 3. DB 연동 및 API

### 3.1 호출 API
- `GET /api/admin/reviews` (필터, 검색, 페이징)
- `POST /api/admin/reviews/:id/hide` (숨김 처리)
- `POST /api/admin/reviews/:id/unhide` (숨김 해제)
- `DELETE /api/admin/reviews/:id` (관리자 권한 소프트 삭제)

### 3.2 참조 테이블 및 정책 (DB.md §3.8)
- `reviews`:
  - `hidden_by`: 처리한 관리자 ID (`profiles.id` FK)
  - `hidden_reason`: 숨김 사유
  - `deleted_at`: 소프트 삭제 시각
- RLS 정책:
  - 일반 공개 SELECT: `deleted_at IS NULL AND hidden_by IS NULL`
  - 관리자 SELECT: 삭제 및 숨김 포함 전체 조회 허용.

---

## 4. 예외 상태 (Error States)

### 4.1 이미 작성자에 의해 삭제된 리뷰
- 관리자가 조치하기 전 작성자가 이미 삭제한 경우:
  - `"작성자가 이미 삭제한 리뷰입니다."` 안내 및 상태 갱신.

---

## 5. 완료 조건 (Acceptance Criteria)

1. [ ] 관리자 리뷰 테이블에서 전국의 텍스트 리뷰와 신고 접수 내역을 확인할 수 있다.
2. [ ] 키워드 검색 및 신고 접수 리뷰 필터링이 정상 동작한다.
3. [ ] [숨김 처리] 시 사유가 저장되고 일반 공개 화면에서 즉시 숨겨진다.
4. [ ] [삭제] 시 `deleted_at`이 설정되어 소프트 삭제 처리된다.
