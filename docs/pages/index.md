# 페이지 명세: 서비스 소개 페이지 (`index.html`)

> 상태: **확정 (사용자 승인 2026-11-05)** · 구현 완료  
> 목적: 서비스(Next.js 앱) 개발 전까지 ALLNIGHT를 소개하는 정적 페이지. 기존 랜딩페이지 문구를 그대로 살린다.  
> **SITEMAP과의 관계:** SITEMAP.md §1은 `/`를 지도 화면으로 정하고 별도 홍보 랜딩을 두지 않는다. 이 페이지는 앱이 생기기 전까지의 **임시 페이지**이며, 앱 개발 시 제거하거나 [Later] "서비스 소개·도움말"(SITEMAP §2)로 옮긴다.

---

## 1. 공통 규칙

- 스타일은 `css/style.css` 하나만 사용한다. `<style>` 태그와 `style=""` 속성을 쓰지 않는다.
- Pretendard 폰트는 `style.css` 안에서 불러온다 (HTML에는 스타일시트 링크 1개만).
- 색·간격·글자 크기는 `style.css`의 변수(DESIGN.md §2 토큰)를 쓴다.
- KO/EN 언어 전환은 기존 동작을 유지한다.
- 데스크톱(1024px 이상) 기준. 좁은 화면은 깨지지 않을 정도만 맞춘다 (DESIGN.md §4).

## 2. 머리말 (header)

| 요소 | 내용 | 동작 |
|---|---|---|
| 로고 | 🌙 ALLNIGHT | 페이지 맨 위로 이동 |
| 메뉴 1 | 장소 찾기 | 체험 데모(`#demo`)로 스크롤 |
| 메뉴 2 | 장소 제보 | 비활성 + "준비 중" 표시 (앱 미개발) |
| 메뉴 3 | 로그인 | 비활성 + "준비 중" 표시 (앱 미개발) |
| 언어 전환 | KO / EN | 기존과 동일 |

- 원래 요청의 "내 책"(마이페이지)은 SITEMAP에서 [Later]이고, 13_later_pages.md에 따라 1차에서는 메뉴를 노출하지 않으므로 넣지 않는다.
- 비활성 메뉴는 클릭해도 이동하지 않으며 `aria-disabled="true"`로 표시한다.
- 기존 섹션 이동 메뉴(문제의식, 시장 환경, 비교분석 등)는 제거한다.

## 3. 본문

기존 랜딩페이지의 섹션과 문구(KO/EN)를 순서 그대로 유지한다.

1. 히어로 — 한 줄 소개, 핵심 수치
2. 문제의식 (`#problem`) — 사용자 목소리 포함
3. 시장 환경 (`#market`)
4. 핵심 솔루션 (`#features`)
5. 체험 데모 (`#demo`) — 시간 슬라이더·태그 필터·결과 3열
6. 비교 분석 (`#comparison`)
7. 로드맵 (`#roadmap`)
8. 마무리 안내 (CTA)
