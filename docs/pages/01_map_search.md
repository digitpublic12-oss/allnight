# 페이지 명세: 지도 및 검색 결과 목록 (`/`)

> 경로: `/`  
> 상태: [MVP] 1차 구현 대상  
> 대상 플랫폼: 데스크톱 웹 (최소 해상도 1024px)  
> 레이아웃: 전면 네이버 지도 바탕 + 왼쪽 플로팅 400px 검색/목록 패널

---

## 1. 페이지 목적 및 접근 권한

### 1.1 페이지 목적
- 방문 즉시 지도와 검색 패널을 제공하여 야간(18:00~익일 07:00 중심)에 이용 가능한 전국의 장소를 시간대별·위치별·카테고리별로 빠르게 탐색한다.
- 불필요한 홍보용 랜딩 페이지를 배제하고 실용적인 탐색 중심의 단일 화면 셸(Shell) 역할을 수행한다.

### 1.2 접근 권한
- **모든 사용자 접근 가능 (비회원, 로그인 회원, 관리자 공통 허용)**
- 로그인하지 않은 비회원도 장소 탐색, 필터링, 지도 이동, 검색 결과 조회가 완전히 가능하다.

---

## 2. UI 구성과 사용자 동작

### 2.1 화면 레이아웃 (DESIGN.md §4)
- **오른쪽 전체 바탕**: 네이버 지도 캔버스 (전체 viewport 크기).
- **왼쪽 플로팅 패널**: 고정 너비 `400px` 패널이 지도 위에 플로팅 배치. 패널 접기/펼치기 버튼 제공.
- **지도 위 플로팅 컨트롤**:
  - 지도 우측/상단: 줌 인/아웃 컨트롤, 현재 위치 버튼.
  - 지도 상단 중앙/우측: **'이 지역 검색' 버튼** (지도가 드래그/줌 된 후 활성화/노출).
  - 지도 우측 상단 플로팅 메뉴: **장소 제보** (클릭 시 신규 제보 패널 오픈), **로그인 / 프로필** (로그인 모달 또는 계정 안내), **테마 토글** (라이트/다크 모드 전환).
  - *주의: 관리자 메뉴 링크 및 [Later] 즐겨찾기 버튼은 노출하지 않음.*

### 2.2 왼쪽 패널 상단 고정 영역 (검색 & 필터)
1. **검색바**:
   - 장소명, 주소, 키워드 입력 필드 (`input height 36px`).
   - 엔터 입력 또는 검색 아이콘 클릭 시 즉시 검색 실행.
2. **시간 선택 영역 (타임라인 슬라이더)**:
   - **모드 전환**: [특정 시각] vs [시간 구간 (시작-종료)] 토글.
   - **기준 날짜**: 기본값 오늘(Asia/Seoul). 날짜 변경 가능 (미래 날짜 상한 제한 없음).
   - **타임라인 슬라이더**: 18:00 ~ 익일 07:00 범위, **30분 단위** 스냅.
   - **동작**: 슬라이더 조작 중에는 선택된 시각 레이블만 즉시 갱신되고, 마우스를 놓았을 때(onAfterChange / debounced) 검색 요청을 전송.
   - **자정 넘김 표시**: 00:00 이후 시각은 '+1일' 또는 '익일' 뱃지로 명확히 표기.
3. **카테고리 필터 (가로 스크롤 칩)**:
   - 8개 표준 카테고리: `음식·카페`, `쇼핑·생활`, `학습·업무`, `의료·응급`, `여가·문화`, `운동·건강`, `교통·이동`, `기타`.
   - 복수 선택 가능. 선택 시 블루 포인트 컬러 강조.
   - 칩 선택/해제 즉시 검색 결과 갱신.
4. **접을 수 있는 고급 필터 (펼치기/접기 버튼)**:
   - **영업정보 검증 상태**: `확인됨(verified)`, `확인 필요(needs_check)`, `미확인(unverified)` 필터 체크박스.
   - **24시간 영업만 보기**: 토글 스위치 / 체크박스.
   - **관리자 지정 표준 태그**: 태그 검색 입력 및 추천 태그 목록에서 선택 (사용자 자유 해시태그 없음).
   - **필터 초기화 버튼**: 모든 필터를 기본 상태(현재 시각, 전체 카테고리, 전체 검증 상태)로 초기화.

### 2.3 왼쪽 패널 하단 스크롤 영역 (검색 결과 목록)
- 독립 스크롤 영역. 카드 형태가 아닌 **컴팩트한 텍스트 행(Row)** 리스트.
- **결과 그룹 분리 (엄격한 정렬 규칙 준수)**:
  1. **전체 영업 (`full`)**: 선택한 시간(구간 전체)에 확실히 영업하는 장소. (지도 중심점 거리순 정렬)
  2. **일부 영업 (`partial`)**: 선택 구간 중 일부 시간만 영업하는 장소. (겹치는 실제 영업 분수 내림차순 후 거리순 정렬, 중립 라벨 표기)
  3. **영업정보 미확인 (`unknown`)**: 해당 시간에 대한 영업 정보가 미확인인 장소. (하단 별도 그룹, 앰버 경고 아이콘 + '영업정보 미확인' 표기, 거리순 정렬)
  4. **영업하지 않음 (`closed`)**: 선택 시간에 영업하지 않는 장소. (최하단 별도 그룹, 중립 톤 표기, 거리순 정렬)
- **각 장소 행 표시 정보**:
  - 1차: 장소명, 선택 시간 영업 상태 뱃지 (`full`/`partial`/`unknown`/`closed`).
  - 2차: 카테고리, 간략한 지역명(시·군·구 / 동), 거리.
  - 3차 (해당 시): 관리자 검증 상태 뱃지, '정보 오래됨(30일 초과)' 앰버 경고, '영업 여부 제보 있음' 경고.
  - 긴 텍스트는 말줄임 처리.
- **장소 클릭 동작**:
  - 클릭한 장소의 행은 연한 블루 배경 및 좌측 강조선 적용.
  - 지도는 해당 장소 좌표로 부드럽게 이동(PanTo)하고 마커를 선택 강조 상태로 전환.
  - 왼쪽 패널이 **장소 상세 패널 (`/place/:placeId`)**로 전환 (스택 방식 이동, 브라우저 히스토리 push).

### 2.4 지도 마커 인터랙션
- 결과 목록의 장소들이 지도 상에 마커로 렌더링.
- 마커 형태:
  - `full`: 채워진 원형 마커 (Primary Blue).
  - `partial`: 외곽선 원형 마커 (Neutral Border).
  - `unknown`: 앰버 경고 원형 마커 (Amber).
  - `closed`: 채도가 낮은 원형 마커.
- 선택된 마커: 크기 확대 + 외곽선 강조 링.
- 마커 클릭 시: 해당 장소 행으로 목록 스크롤 이동 및 장소 상세 패널 오픈.
- 밀집 지역: 네이버 지도 클러스터링 적용.
- **지도 이동 및 '이 지역 검색'**:
  - 지도를 드래그하거나 줌을 변경해도 자동으로 검색이 재실행되지 않음.
  - 지도 상단에 **'이 지역 검색'** 버튼이 활성화됨. 사용자가 버튼을 클릭해야 현재 지도 bounds를 기준으로 검색 갱신.
  - 단, 지도가 이동된 상태라도 시간/카테고리 필터를 변경하면 **'마지막으로 확정된 검색 영역'**을 기준으로 즉시 검색.

### 2.5 URL 쿼리 파라미터 동기화
- 검색어(`q`), 시작 시각(`startAt`), 종료 시각(`endAt`), 카테고리(`categories`), 검증 상태(`verifications`), 24시간 여부(`only24h`), 지도 영역 좌표 등이 URL 쿼리 스트링으로 직렬화/복원됨.
- 링크 복사/공유, 브라우저 새로고침 시 동일한 검색 조건 및 목록 상태 복원.

## 3. DB 연동 및 API

### 3.1 호출 API
- `POST /api/places/search` (또는 Supabase RPC `search_places(...)`)
- **요청 파라미터**:
  ```json
  {
    "bounds": { "north": 37.55, "south": 37.45, "east": 127.05, "west": 126.95 },
    "center": { "lat": 37.50, "lng": 127.00 },
    "startAt": "2026-11-05T23:00:00+09:00",
    "endAt": "2026-11-06T03:00:00+09:00",
    "categoryIds": ["uuid-1", "uuid-2"],
    "tagIds": [],
    "verificationStatuses": ["verified", "needs_check"],
    "only24h": false,
    "query": "카페",
    "limit": 50,
    "cursor": null
  }
  ```
- **응답 데이터 구조**:
  - `items`: 장소 목록 배열
    - `id`, `name`, `categoryId`, `categoryName`, `addressFull`, `province`, `cityDistrict`
    - `latitude`, `longitude`, `distanceMeters`
    - `coverageStatus`: `'full' | 'partial' | 'unknown' | 'closed'`
    - `overlapMinutes`: 부분 영업일 경우 겹치는 총 분 수
    - `verificationStatus`: `'verified' | 'needs_check' | 'unverified'`
    - `lastVerifiedAt`: 관리자 최종 실확인 시각
    - `hasPendingCorrection`: 미처리 수정 제보 존재 여부
    - `hasUnresolvedOpeningReport`: 미해결 '영업하지 않음' 제보 존재 여부
    - `isOlderThan30Days`: `lastVerifiedAt` 기준 30일 초과 여부
    - `todayHoursSummary`: 오늘 영업시간 요약 문자열
  - `nextCursor`: 다음 페이지 커서 (페이지네이션 지원)

### 3.2 참조 테이블
- `places` (기본 장소 정보, 위치 PostGIS `location`, `deleted_at IS NULL`)
- `categories` (`is_active = true`)
- `tags`, `place_tags`
- `place_regular_day_status`, `place_regular_intervals` (요일별 영업 스케줄)
- `place_special_days`, `place_special_intervals` (날짜별 예외 스케줄)
- `submissions` (미해결 수정 제보 파악)
- `opening_reports` (미해결 영업 여부 제보 파악)

## 4. 예외 상태 (Empty & Error States)

### 4.1 검색 결과 없음 (Empty State)
- 조건에 부합하는 장소가 0건일 때:
  - 안내 문구: `"선택한 조건에 맞는 심야 영업 장소가 없습니다."`
  - 액션: **[필터 초기화]** 버튼 (클릭 시 기본 필터로 리셋 후 재검색), **[신규 장소 제보하기]** 버튼 (클릭 시 제보 패널 오픈).

### 4.2 네트워크 / DB / 지도 API 오류 (Error State)
- 검색 요청 실패 시 목록 영역에 인라인 오류 안내 표시:
  - 안내 문구: `"장소 정보를 불러오지 못했습니다. 네트워크 상태를 확인해주세요."`
  - 액션: **[다시 시도]** 버튼 제공.
  - 기존 입력 검색어 및 필터 설정값은 초기화되지 않고 안전하게 보존.

### 4.3 지원 최소 화면 너비 미달 (1024px 미만)
- 화면 너비가 1024px 미만인 데스크톱/태블릿/모바일 접속 시:
  - `"Allnight는 1024px 이상의 데스크톱 환경에 최적화되어 있습니다. 더 넓은 화면에서 이용해주세요."` 안내 레이어 표시.

## 5. 완료 조건 (Acceptance Criteria)

1. [ ] 접속 시 `/`에서 전체 화면 네이버 지도와 왼쪽 400px 플로팅 패널이 즉시 표시된다.
2. [ ] 타임라인 슬라이더(18:00~익일 07:00, 30분 단위)로 특정 시각 및 구간 검색이 정상 작동한다.
3. [ ] 검색 결과가 `full` → `partial` → `unknown` → `closed` 4개 그룹 순서대로 정확히 분류되어 표시된다.
4. [ ] 30일 초과 장소에는 '정보 오래됨', 미해결 제보가 있는 장소에는 '영업 여부 제보 있음' 경고가 표시된다.
5. [ ] 지도 이동 시 자동 재검색되지 않고, '이 지역 검색' 버튼 클릭 시에만 검색 영역이 갱신된다.
6. [ ] 검색어, 시간, 필터 변경 시 URL 쿼리 파라미터가 갱신되고, 새로고침 시 검색 조건이 완벽히 복원된다.
7. [ ] 장소 클릭 시 패널이 장소 상세(`02_place_detail.md`)로 부드럽게 전환된다.
