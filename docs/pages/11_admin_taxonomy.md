# 페이지 명세: 관리자 카테고리·태그 관리 (`/admin/taxonomy`)

> 경로: `/admin/taxonomy`  
> 상태: [MVP] 1차 구현 대상  
> 대상 플랫폼: 데스크톱 웹  
> 레이아웃: 관리자 셸 (사이드바 + 2개 탭 뷰)

---

## 1. 페이지 목적 및 접근 권한

### 1.1 페이지 목적
- Allnight 서비스의 분류 체계인 8대 카테고리와 관리형 표준 태그(시설·서비스 / 분위기·특징)를 관리한다.
- 사용자의 무분별한 자유 해시태그 생성을 방지하고 일관된 표준 태그 체계를 유지한다.

### 1.2 접근 권한
- **관리자 전용 (`profiles.role = 'admin'`)**
- 관리자 외 접근 불가.

---

## 2. UI 구성과 사용자 동작

### 2.1 상단 탭 구성
- **[카테고리 관리 탭]** vs **[표준 태그 관리 탭]**

### 2.2 카테고리 관리 탭 (DB.md §3.2)
- 초기 8대 표준 대분류 목록 조회 및 노출 순서 관리:
  - 8개 카테고리: `음식·카페`, `쇼핑·생활`, `학습·업무`, `의료·응급`, `여가·문화`, `운동·건강`, `교통·이동`, `기타`.
- **목록 테이블**:
  - 컬럼: 표시명(`name`), 영문 식별자(`slug`), 정렬 순서(`sort_order`), 활성 상태(`is_active`), 연결된 장소 수, 액션([순서 변경], [편집]).
- *주의: 대분류는 8개 단일 계층으로 고정되며, 하위 카테고리는 생성하지 않음.*

### 2.3 표준 태그 관리 탭 (DB.md §3.3)
- 관리자가 직접 정의한 표준 태그 목록 관리.
- **상단 [+ 새 표준 태그 등록] 버튼**:
  - 클릭 시 모달 오픈.
  - 입력 필드:
    - 태그명 (예: `주차 가능`, `콘센트 많음`, `조용한`)
    - 영문 slug (예: `parking`, `sockets`, `quiet`)
    - 태그 유형: `시설·서비스 (facility)` / `분위기·특징 (atmosphere)`
    - 정렬 순서
- **태그 목록 테이블**:
  - 컬럼: 태그명, slug, 유형 뱃지(`facility` / `atmosphere`), 연결된 장소 수, 활성 상태(토글 스위치), 액션([수정], [비활성화]).
- **삭제/비활성화 정책**:
  - 이미 기존 장소에 연결된 태그를 DB에서 완전 삭제하면 데이터 정합성이 깨지므로, 삭제 대신 **비활성화(`is_active = false`)** 처리를 기본으로 제공.
  - 비활성화된 태그는 신규 제보 및 장소 등록 선택지에서 제외되지만 기존 장소 연결은 유지됨.

---

## 3. DB 연동 및 API

### 3.1 호출 API
- `GET /api/admin/categories`
- `PATCH /api/admin/categories/:id`
- `GET /api/admin/tags`
- `POST /api/admin/tags`
- `PATCH /api/admin/tags/:id`

### 3.2 참조 테이블 (DB.md §3.2, §3.3)
- `categories`: `id`, `slug`, `name`, `sort_order`, `is_active`
- `tags`: `id`, `slug`, `name`, `tag_type`, `sort_order`, `is_active`
- `place_tags`: 연결된 장소 수 카운트 (`COUNT(place_id)`)

---

## 4. 예외 상태 (Error States)

### 4.1 slug 중복 오류
- 이미 등록된 slug와 동일한 영문 식별자 등록 시:
  - `"이미 존재하는 영문 식별자(slug)입니다."` 인라인 경고.

### 4.2 필수 태그명 누락
- 공백 태그명 입력 시 등록 차단.

---

## 5. 완료 조건 (Acceptance Criteria)

1. [ ] 8대 표준 카테고리 목록이 정상 조회되고 표시명 및 정렬 순서를 관리할 수 있다.
2. [ ] 표준 태그 등록 시 `facility`와 `atmosphere` 유형 구분이 정확히 저장된다.
3. [ ] 태그 비활성화 토글 시 신규 선택 목록에서 정상 제외된다.
4. [ ] 사용자 자유 태그 생성이 차단되고 관리자 등록 태그만 유효함을 보장한다.
