# 페이지 명세: 로그인·회원가입 모달

> 경로: 별도 페이지 이동이 아닌 지도 위의 **중앙 모달 (Center Modal)**  
> 상태: [MVP] 1차 구현 대상  
> 대상 플랫폼: 데스크톱 웹  
> 레이아웃: 화면 중앙 팝업 + 배경 딤(Dimmed) 오버레이 + 키보드 포커스 트랩(Focus Trap)

---

## 1. 페이지 목적 및 접근 권한

### 1.1 페이지 목적
- 리뷰 작성 등 회원 전용 기능을 이용하려는 비회원에게 간편한 이메일·비밀번호 기반 인증을 제공한다.
- 인증 완료 후 화면을 초기화하지 않고 **사용자가 직전에 수행하려던 원래 작업으로 즉시 복귀**시킨다.

### 1.2 접근 권한
- **비로그인 사용자 (비회원)**
- 이미 로그인된 상태에서는 본 모달이 노출되지 않으며, 우측 상단 플로팅 메뉴에 로그아웃 액션이 제공된다.

---

## 2. UI 구성과 사용자 동작

### 2.1 모달 기본 인터랙션 (SITEMAP.md §7, DESIGN.md §9)
- **표시 형태**: 화면 정중앙 플로팅 모달 (`width: 380px`, `radius 6px`, 테두리 1px, 배경 다크/라이트 패널 토큰).
- **진입 경로**:
  1. 우측 상단 지도 플로팅 메뉴의 **[로그인]** 클릭.
  2. 비회원 상태에서 장소 상세의 **[리뷰 작성하기]** 버튼 클릭.
  3. 비회원 상태에서 `/admin` 관리자 URL 직접 접근 시.
- **닫기 동작**:
  - 모달 우측 상단의 `[X]` 닫기 버튼 클릭.
  - 배경 어두운 영역(Backdrop) 클릭.
  - 키보드 `ESC` 키 입력.
  - 닫히면 포커스는 모달을 열었던 원래 버튼으로 복원됨.

### 2.2 모달 내부 탭 구성
- 상단에 **[로그인]** / **[회원가입]** 탭 전환 버튼 제공.

#### [로그인 탭]
1. **이메일 주소**: 텍스트 입력 (`type="email"`, 플레이스홀더: `email@example.com`).
2. **비밀번호**: 텍스트 입력 (`type="password"`, 플레이스홀더: `비밀번호 입력`).
3. **[로그인] 버튼**: Primary Blue 버튼.
4. **하단 보조 텍스트**: `"계정이 없으신가요? [회원가입]"` (클릭 시 회원가입 탭으로 전환).

#### [회원가입 탭]
1. **이메일 주소**: 텍스트 입력 (`type="email"`).
2. **비밀번호**: 텍스트 입력 (`type="password"`, 6자 이상).
3. **비밀번호 확인**: 텍스트 입력 (`type="password"`).
4. **닉네임 정책 안내 (DB.md §3.1)**:
   - 회원가입 시 사용자가 닉네임을 직접 입력하도록 요구하지 않음.
   - 안내 문구: `"가입 시 시스템에서 랜덤 닉네임(예: 새벽고양이482)이 자동으로 부여됩니다."`
5. **[회원가입 완료] 버튼**: Primary Blue 버튼.

### 2.3 인증 완료 후 후속 동작
- **리뷰 작성 중 진입했던 경우**:
  - 모달이 닫히고, 장소 상세 패널의 리뷰 작성 입력창에 포커스가 유지되어 즉시 텍스트 작성이 가능하도록 상태 복귀.
- **일반 플로팅 메뉴에서 진입했던 경우**:
  - 모달이 닫히고, 기존 지도 위치, 검색어, 타임라인 시간, 필터 상태를 100% 유지.
  - 우측 상단 메뉴가 `[로그인]` → `[내 프로필 / 로그아웃]`으로 전환.
- **성공 피드백**: 화면 우측 하단에 `"로그인되었습니다."` 또는 `"회원가입이 완료되었습니다."` 성공 토스트 노출.

### 2.4 로그아웃 동작
- 우측 상단 메뉴의 [로그아웃] 클릭 시:
  - Supabase 세션 종료.
  - 지도의 현재 위치, 검색 조건, 필터는 그대로 유지되며, 화면만 비회원 상태로 즉각 갱신.

## 3. DB 및 인증 연동

### 3.1 Supabase Auth 호출
- **로그인**: `supabase.auth.signInWithPassword({ email, password })`
- **회원가입**: `supabase.auth.signUp({ email, password })`
- **로그아웃**: `supabase.auth.signOut()`

### 3.2 `profiles` 테이블 자동 생성 불변조건 (DB.md §3.1, §8.1)
- `auth.users`에 신규 유저가 생성되면 PostgreSQL 트리거(또는 인증 핸들러)가 즉시 실행:
  - `id`: `auth.users.id`
  - `nickname`: 서버에서 랜덤 생성 (예: 형용사 + 동물/사물 + 숫자 형태 난수, 중복 방지).
  - `role`: 무조건 `'member'`로 강제 설정 (클라이언트에서 `admin` 지정 절대 불가).

## 4. 예외 상태 (Error States)

### 4.1 로그인 실패
- 이메일 불일치 또는 비밀번호 불일치:
  - `"이메일 또는 비밀번호가 올바르지 않습니다."` 인라인 경고 표시.
- 비밀번호 입력 필드 초기화 및 비밀번호 입력창으로 포커스 이동.

### 4.2 회원가입 유효성 오류
- 비밀번호와 비밀번호 확인 불일치: `"비밀번호가 일치하지 않습니다."`
- 비밀번호 자릿수 미달 (6자 미만): `"비밀번호는 최소 6자 이상이어야 합니다."`
- 이미 가입된 이메일: `"이미 사용 중인 이메일 주소입니다."`

## 5. 완료 조건 (Acceptance Criteria)

1. [ ] 플로팅 메뉴 또는 리뷰 작성 버튼 클릭 시 화면 중앙 모달 형태로 정상 표시된다.
2. [ ] ESC 키 입력, 배경 오버레이 클릭, 닫기 버튼 클릭 시 모달이 닫히고 포커스가 복원된다.
3. [ ] 이메일·비밀번호로 신규 회원가입 시 랜덤 닉네임이 부여된 `member` 프로필이 자동 생성된다.
4. [ ] 로그인 완료 시 모달이 닫히며 원래 하려던 작업(리뷰 작성 등)으로 안전하게 복귀한다.
5. [ ] 로그인 및 로그아웃 시 지도의 좌표, 검색어, 시간 슬라이더 필터 상태가 손실되지 않는다.
