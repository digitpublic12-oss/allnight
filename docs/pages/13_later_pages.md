## 1. 즐겨찾기 패널 [Later]

### 1.1 개요 및 목적
- 로그인한 회원이 자주 찾는 야간 장소를 저장하고 왼쪽 패널에서 모아볼 수 있는 개인화 목록 기능.

### 1.2 UI 구성 및 흐름
- **진입 경로**: 지도 우측 상단 플로팅 메뉴에 [즐겨찾기] 버튼 추가 (로그인 필요).
- **왼쪽 패널 레이아웃**:
  - 패널 타이틀: `"저장한 장소"`
  - 저장 장소 목록: 컴팩트한 행 리스트 (장소명, 카테고리, 오늘 영업시간, 저장 해제 버튼).
  - 항목 클릭 시: 같은 패널에서 해당 장소의 상세 패널(`02_place_detail.md`)로 전환.
  - 빈 상태: `"아직 저장한 장소가 없습니다. 마음에 드는 장소를 즐겨찾기에 추가해보세요."`
- **DB 연동 사전 준비**:
  - 1차 배포 시 `favorites` 테이블 및 RLS(`user_id = auth.uid()`)는 **선생성**되어 있음 (DB.md §3.13). UI 연결만 2차에 수행.

## 2. 회원 마이페이지 [Later]

### 2.1 개요 및 목적
- 로그인 회원이 자신의 활동 내역(내 리뷰, 내 제보 처리 상태, 프로필 닉네임)을 통합 관리하는 전용 공간.

### 2.2 메뉴형 홈 및 하위 섹션
- **진입 경로**: 우측 상단 메뉴의 [내 계정 / 마이페이지] 클릭 시 왼쪽 패널로 진입.
- **메뉴 홈 구성**:
  1. **내 리뷰 관리**:
     - 본인이 작성한 전체 리뷰 목록.
     - 리뷰 선택 시 해당 장소 상세로 이동하여 본인 리뷰 위치를 강조 표시.
     - 인라인 수정 및 삭제 지원.
  2. **내 제보 내역**:
     - 본인이 제출한 신규 장소 및 정보 수정 제보의 처리 상태 조회:
       - `접수 완료 (received)`
       - `검토 중 (in_review)`
       - `승인 완료 (approved)`
       - `반려 (rejected)`: 관리자가 작성한 **반려 사유(`rejection_reason`)** 상세 조회.
     - *주의: 비회원 제보는 계정과 연결되지 않으므로 회원 마이페이지 조회 대상에서 제외.*
  3. **프로필 설정**:
     - 가입 시 랜덤 부여된 닉네임 확인 및 본인이 원하는 닉네임으로 1회 변경 기능.
     - 이메일 확인 및 로그아웃/회원 탈퇴 안내.

## 3. 서비스 소개 및 도움말 [Later]

### 3.1 개요
- 서비스의 취지(왜 Allnight인가, 심야 영업시간의 불일치 문제), 영업시간 판정 원칙, 정보 신뢰도 뱃지 설명, 관리자 및 이용자 제보 참여 방법 안내.
- 왼쪽 패널의 정적 도움말 아티클 형태로 후속 구현.

## 4. MVP 완료 기준 체크

1. [ ] MVP 릴리즈 빌드에서는 즐겨찾기 및 마이페이지 진입 버튼이 일반 사용자 UI에 노출되지 않는다.
2. [ ] 장소 상세 화면의 [즐겨찾기] 버튼은 비노출되거나 비활성화 처리되어 있다.
3. [ ] `favorites` 테이블은 DB에 생성되어 마이그레이션 호환성을 유지한다.
