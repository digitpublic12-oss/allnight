# 페이지 명세: 장소 상세 패널 (`/place/:placeId`)

> 경로: `/place/:placeId`  
> 상태: [MVP] 1차 구현 대상  
> 대상 플랫폼: 데스크톱 웹  
> 레이아웃: 전면 네이버 지도 유지(선택 장소로 핀 이동) + 왼쪽 플로팅 400px 상세 패널

---

## 1. 페이지 목적 및 접근 권한

### 1.1 페이지 목적
- 특정 장소의 심야 영업시간, 관리자 검증 상태, 주간 스케줄, 위치, 편의시설 태그, 사용자 텍스트 리뷰를 종합적으로 제공한다.
- 고유 URL을 통해 직접 링크 공유 및 새로고침이 가능하며, 사용자에게 정보 신뢰도와 오류 제보 경로를 투명하게 제공한다.

### 1.2 접근 권한
- **열람**: 모든 사용자 (비회원, 로그인 회원, 관리자 공통 허용)
- **리뷰 작성·수정·삭제**: 로그인 회원만 가능 (본인 작성 리뷰만 수정/소프트 삭제 가능)
- **정보 수정 제보**: 비회원, 로그인 회원 모두 가능 (로그인 없이 제출 가능)
- **실제 영업 여부 제보**: 로그인 회원 (비회원 허용 여부는 미결정 사항 보고 참조)

## 2. UI 구성과 사용자 동작

### 2.1 상단 네비게이션 및 헤더
1. **뒤로가기 버튼 (`< 뒤로`)**:
   - 패널 최상단 좌측에 위치.
   - 클릭 시 이전 검색 결과 목록 패널로 복귀하며 기존 검색어, 타임라인 시간, 필터, 스크롤 위치, 지도 좌표를 완벽히 복원.
2. **대표 사진 헤더 (DESIGN.md §8, Q1 확정)**:
   - **대표 사진이 DB에 존재할 때만** 상단에 렌더링 (가로 폭 100%, 적정 비율).
   - 등록된 사진이 없거나 불러오지 못할 경우 **사진 영역 자체를 완전히 생략** (빈 플레이스홀더를 두지 않음).
3. **장소명 및 카테고리**:
   - 장소명 (`text 20px semibold`).
   - 카테고리 뱃지 (`text 12px`, 8대 표준 카테고리 중 1개).

### 2.2 영업 판정 및 신뢰도 상태 (상단 최우선 정보)
1. **선택 시각/구간 영업 판정 결과**:
   - 검색 조건에서 선택한 시각(또는 현재 시각) 기준의 영업 판정:
     - `전체 영업 (full)`: 블루 뱃지 + "선택 시간 영업 중"
     - `일부 영업 (partial)`: 중립 뱃지 + "선택 시간 중 일부 영업 (예: ~02:00까지)"
     - `영업정보 미확인 (unknown)`: 앰버 뱃지 + "영업정보 미확인 (방문 전 확인 권장)"
     - `영업하지 않음 (closed)`: 그레이 뱃지 + "영업 종료 (휴무)"
2. **신뢰도 및 경고 상태 표시 (SITEMAP.md §5, PRD.md §7)**:
   - **검증 상태 뱃지**: `관리자 확인됨(verified)` / `확인 필요(needs_check)` / `미확인(unverified)`.
   - **마지막 실확인일**: 관리자가 실제로 영업정보를 검증한 날짜 표기 (예: `2026.10.15 확인`).
   - **정보 오래됨 경고**: 마지막 확인일로부터 30일 초과 시 앰버 경고 박스 노출 (`"확인된 지 30일 이상 지난 정보입니다. 실제 영업 여부를 확인해주세요."`).
   - **영업 여부 제보 있음 경고**: '문 닫음' 제보가 접수되어 미해결 상태인 경우 노출 (`"최근 영업하지 않는다는 이용자 제보가 접수되었습니다."`).
   - **정보 수정 제보 접수 주의 표시**: 미처리 수정 제보가 접수된 경우 노출 (`"현재 정보 수정 제보가 접수되어 검토 중입니다."`).

### 2.3 주요 행동 버튼 그룹
- 장소명 바로 아래 가로 정렬 버튼 바:
  1. **[길찾기]**: 클릭 시 네이버 지도 길찾기 웹 링크를 새 탭으로 오픈 (좌표 및 장소명 연동).
  2. **[정보 수정 제보]**: 클릭 시 현재 장소 정보가 프리필된 **'정보 수정 제보 패널'(`04_place_correction.md`)**로 전환.
  3. **[즐겨찾기]**: [Later] 항목이므로 MVP에서는 **버튼 비노출** (또는 비활성화).

### 2.4 영업시간 상세 섹션
1. **오늘의 영업시간**:
   - 당일 기준 영업시간 요약 (예: `18:00 ~ 익일 04:00`, `24시간 영업`, `정기 휴무`).
   - 브레이크타임이 있는 경우 다중 구간 표시 (예: `11:00~15:00, 17:00~02:00`).
2. **적용되는 날짜별 예외 안내**:
   - 임시 휴무, 특별 영업시간 등 예외가 존재하는 날짜의 경우 시간표 상단에 항상 눈에 띄게 안내.
3. **주간 7일 시간표 펼치기 (기본 접힘, Q2 확정)**:
   - 기본적으로는 접혀 있으며, **['주간 영업시간 전체보기 ▾']** 버튼을 클릭하여 요일별(월~일) 정기 영업시간 및 휴무일을 아코디언 형태로 펼침.
   - 자정 이후 종료 구간은 '익일 HH:mm'으로 명확히 표현.

### 2.5 장소 기본 정보 (연속 스크롤)
- 데이터가 존재하는 항목만 조건부 렌더링:
  - **도로명 주소 / 지번 주소 / 상세 주소**: 주소 복사 버튼 제공.
  - **전화번호**: 클릭 시 전화 걸기(`tel:`) 링크 (전화번호 있을 때만 노출).
  - **웹사이트**: 외부 링크 버튼 (웹사이트 URL 있을 때만 노출).
  - **표준 태그/편의시설**: 관리자 등록 태그 칩 (예: `#주차가능`, `#콘센트많음`, `#조용한분위기`).

### 2.6 실제 영업 여부 제보 진입점
- *"오늘 이 장소를 방문하셨나요?"* 인라인 카드:
  - **[영업 중이었어요]** / **[문이 닫혀 있었어요]** 빠른 제보 버튼 제공.
  - 비회원 클릭 시 로그인 안내 또는 제보 접수 (미결정 정책에 따름).
  - 제출 시 성공 토스트 노출 및 관리자 검토 큐로 전달.

### 2.7 텍스트 리뷰 섹션
- 별도의 탭으로 분리하지 않고 상세 정보 하단에 **연속 스크롤**로 배치.
- **특징**: **별점 없음**, **리뷰 사진 첨부 없음**, **순수 텍스트 중심**.
- **리뷰 작성 폼**:
  - 로그인 회원: 텍스트 입력창 (`textarea`, 최대 2,000자 제한) + [등록] 버튼.
  - 비회원: 입력창 포커스 또는 클릭 시 **중앙 로그인 모달(`05_auth_modal.md`)** 표시, 로그인 완료 후 원래 작성 상태로 복귀.
  - 실제 방문 당시 영업 상태 선택 체크박스 (선택 사항: `방문 당시 정상 영업 중이었음`).
- **리뷰 목록**:
  - 작성자 닉네임 (프로필 닉네임), 작성일, 리뷰 본문.
  - 본인이 작성한 리뷰: **[수정]**, **[삭제]** 버튼 노출.
    - [수정]: 인라인 편집 모드로 전환되어 본문 수정 후 저장.
    - [삭제]: 삭제 확인 대화상자 노출 후 확인 시 소프트 삭제(`deleted_at = now()`).
  - 부적절한 리뷰 신고 버튼 (신고 시 관리자 검토 대기).
  - 리뷰가 없을 때: `"첫 번째 방문 후기를 남겨주세요."` 안내.

## 3. DB 연동 및 API

### 3.1 호출 API 및 쿼리
- `GET /api/places/:placeId?startAt=...&endAt=...`
  - 장소 단건 상세 조회 및 현재 선택 시간 기준 `coverageStatus` 판정.
- `GET /api/places/:placeId/reviews`
  - 해당 장소의 활성 리뷰 목록 조회 (`deleted_at IS NULL`, `hidden_by IS NULL`, `ORDER BY created_at DESC`).
- `POST /api/places/:placeId/reviews` (회원 전용)
  - 리뷰 신규 작성 (`body`, `author_id = auth.uid()`).
- `PATCH /api/reviews/:reviewId` (작성자 본인 전용)
  - 본인 리뷰 본문 수정.
- `DELETE /api/reviews/:reviewId` (작성자 본인 또는 관리자)
  - 본인 리뷰 소프트 삭제 (`deleted_at = now()`).
- `POST /api/places/:placeId/opening-reports`
  - 실제 영업 여부 제보 (`reported_status: 'open' | 'closed' | 'uncertain'`).

### 3.2 참조 테이블
- `places` (기본 정보, 위경도, 카테고리, 검증 상태)
- `place_photos` (`ORDER BY sort_order ASC, created_at ASC LIMIT 1` -> 대표 사진)
- `place_regular_day_status`, `place_regular_intervals` (정기 시간)
- `place_special_days`, `place_special_intervals` (예외 시간)
- `tags`, `place_tags` (태그 정보)
- `reviews`, `profiles` (리뷰 및 작성자 닉네임)
- `opening_reports` (미해결 영업 제보 여부)
- `submissions` (미해결 수정 제보 여부)

## 4. 예외 상태 (Error States)

### 4.1 존재하지 않거나 삭제된 장소 URL (`/place/invalid-id`)
- 별도의 전체 404 에러 페이지로 이동하지 않음.
- 지도는 마지막 위치 또는 서울 중심 좌표를 유지한 채, 왼쪽 패널에 **'장소를 찾을 수 없습니다'** 안내 패널 표시:
  - 안내 문구: `"요청하신 장소 정보가 존재하지 않거나 삭제되었습니다."`
  - 액션: **[지도 검색으로 돌아가기]** 버튼 (클릭 시 `/` 검색 패널로 전환).

### 4.2 상세 정보 로딩 실패
- 네트워크 또는 DB 에러로 상세 데이터 조회가 실패한 경우:
  - 패널 내 오류 메시지 + **[다시 시도]** 버튼 표시.
  - 뒤로가기 버튼은 정상 작동하여 목록으로 안전하게 복귀 가능.

### 4.3 삭제된 리뷰 / 권한 없는 수정 시도
- 이미 삭제된 리뷰에 대한 수정/삭제 요청이나 타인의 리뷰 수정 시도시:
  - `"수정 권한이 없거나 이미 삭제된 리뷰입니다."` 에러 토스트 표시 후 최신 리뷰 목록 갱신.

## 5. 완료 조건 (Acceptance Criteria)

1. [ ] `/place/:placeId` 진입 시 지도가 해당 좌표로 이동하고 핀이 강조 표시된다.
2. [ ] 대표 사진이 있는 장소는 최상단에 사진 헤더가 표시되고, 없는 장소는 사진 영역이 완전히 생략된다.
3. [ ] 선택 시간의 영업 판정(`full`/`partial`/`unknown`/`closed`)과 관리자 검증 상태가 상단에 명확히 표기된다.
4. [ ] 30일 초과 시 '정보 오래됨', 미해결 제보 시 '영업 여부 제보 있음', 수정 제보 접수 시 '주의' 문구가 정상 노출된다.
5. [ ] 주간 7일 시간표는 기본 접힘 상태이며, '전체보기' 클릭 시 펼쳐진다.
6. [ ] 텍스트 리뷰 목록 조회 및 회원의 작성, 수정, 삭제(소프트 삭제)가 정상 작동한다.
7. [ ] 비회원이 리뷰 작성 시도 시 중앙 로그인 모달이 뜨고, 로그인 후 작성 단계로 복귀한다.
8. [ ] [뒤로가기] 클릭 시 이전 검색 조건(시간, 필터, 스크롤 위치)이 유지된 채 목록 패널로 복귀한다.
9. [ ] 존재하지 않는 장소 ID 접근 시 지도 위 '장소를 찾을 수 없습니다' 패널이 표시된다.
