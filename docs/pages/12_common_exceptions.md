# 페이지 명세: 공통 상태 및 예외 처리 (`docs/pages/12_common_exceptions.md`)

> 상태: [MVP] 1차 구현 대상  
> 대상 플랫폼: 데스크톱 웹  
> 목적: 서비스 전반의 공통 오류, 빈 상태, 권한 예외, 이탈 확인, 해상도 제약의 일관된 사용자 경험 정의 (SITEMAP.md §10, DESIGN.md §10)

---

## 1. 예외 및 상태 목록

| 상황 | 발생 조건 | 화면 표현 및 동작 | 복구 및 사용자 액션 |
|---|---|---|---|
| **접근 권한 없음 (403)** | 일반 회원이 `/admin` 직접 접근 | 관리자 셸 대신 '접근 권한 없음' 전면 화면 표시 | **[메인 지도로 돌아가기]** 버튼 제공 |
| **존재하지 않는 장소 (404)** | 삭제되었거나 잘못된 장소 URL (`/place/invalid-id`) | 전면 404 페이지 대신 **지도 유지 + 왼쪽 패널 '장소 없음' 안내** | **[검색 목록으로 복귀]** 버튼 제공 |
| **검색 결과 없음 (Empty)** | 필터/지역/시간 조건에 맞는 장소가 0건일 때 | 목록 영역에 안내 배너 표시 | **[필터 초기화]** 및 **[신규 장소 제보]** 버튼 |
| **API/DB/네트워크 오류** | 서버 통신 실패, Supabase 일시 에러 | 해당 패널 내 인라인 오류 카드 표시 (기존 입력 보존) | **[다시 시도]** 버튼 제공 |
| **지도 로딩 실패** | 네이버 지도 API 인증 실패 또는 네트워크 단절 | 지도 영역에 안내 배경 + 에러 메시지 | **[지도 새로고침]** 버튼 |
| **작성 중 이탈 확인** | 제보/수정 폼 입력 중 닫기 또는 뒤로가기 클릭 | 화면 중앙에 이탈 확인 다이얼로그 노출 | **[계속 작성]** vs **[나가기(삭제)]** |
| **비회원 기능 제한** | 비회원이 리뷰 작성 시도 | 중앙 로그인 모달 오픈 | 로그인 성공 시 **작성하던 장소/입력 상태로 복귀** |
| **로그아웃** | 사용자가 우측 상단 메뉴에서 로그아웃 | 세션 종료, 화면 리셋 없음 | 지도 위치, 검색어, 타임라인 시간, 필터 100% 유지 |
| **해상도 미달 (1024px 미만)** | 브라우저 너비가 1024px 미만인 기기 접근 | 데스크톱 최적화 안내 오버레이 표시 | 브라우저 창 확대 유도 (모바일 UI 미구현) |
| **브라우저 뒤로가기** | 브라우저 뒤로/앞으로 버튼 클릭 | 패널 스택을 단계별로 복원 | 이전 패널, 검색 조건, 목록 스크롤 위치 복원 |

## 2. 세부 화면 구성 및 복구 정책

### 2.1 접근 권한 없음 화면 (403 Forbidden)
- **UI 구성**:
  - 중앙 정렬 레이아웃: 잠금 아이콘(Lucide ShieldAlert), `"접근 권한이 없습니다"`.
  - 서브 문구: `"이 페이지는 관리자 전용 공간입니다. 관리자 계정으로 로그인 후 다시 시도해주세요."`
  - 액션 버튼: **[Allnight 메인 지도로 이동]** (클릭 시 `/`로 이동).

### 2.2 삭제되거나 없는 장소 URL (404 Not Found)
- **UI 원칙**: 지도를 날려버리는 전체 404 페이지를 띄우지 않고, **지도를 유지한 채 왼쪽 패널만 오류 상태**로 표시 (SITEMAP.md §3).
- **왼쪽 패널 구성**:
  - 상단 뒤로가기 버튼 (`< 뒤로`).
  - 안내 문구: `"장소를 찾을 수 없습니다."`
  - 설명: `"요청하신 장소 정보가 존재하지 않거나, 삭제되었을 수 있습니다."`
  - 액션 버튼: **[지도 검색 목록으로 이동]** (클릭 시 패널이 `/` 검색 결과로 전환).

### 2.3 검색 결과 없음 (Empty State)
- **UI 구성**:
  - 목록 스크롤 영역 중앙에 검색 아이콘 + `"조건에 맞는 심야 영업 장소가 없습니다."`
  - 가이드: *"시간 필터를 넓히거나 다른 카테고리를 선택해보세요."*
  - 액션 버튼 바:
    - **[필터 전체 초기화]**: 시간/카테고리/검증상태 필터를 기본값으로 리셋 후 재검색.
    - **[이 장소 제보하기]**: 신규 장소 제보 패널 오픈.

### 2.4 네트워크 / DB 로딩 오류 (Error State)
- **UI 원칙**: 입력 중이던 검색어, 필터 칩 선택 상태, 제보 폼의 텍스트가 절대 초기화되지 않아야 함.
- **표시 형태**:
  - 패널 내 경고 배너: `"일시적인 오류로 데이터를 불러오지 못했습니다."`
  - **[다시 시도]** 버튼: 클릭 시 이전 실패한 API 요청만 재전송.

### 2.5 작성 중 이탈 확인 모달 (Dirty Exit Dialog)
- **트리거**: 폼 필드 중 하나라도 사용자가 수정한 상태에서 상단 [취소], 패널 닫기, 또는 브라우저 히스토리 popstate 발생 시.
- **모달 내용**:
  - 타이틀: `"작성을 취소하시겠습니까?"`
  - 본문: `"입력하신 모든 내용이 삭제되며 복구할 수 없습니다."`
  - 버튼: **[계속 작성하기]** (모달 닫힘, 포커스 복원) / **[나가기]** (폼 폐기 후 이전 화면 복귀).

### 2.6 지원 최소 해상도 미달 안내 (Viewport < 1024px)
- **UI 원칙**: MVP는 데스크톱 전용이며 모바일 전용 탐색 UI는 범위 밖 (PRD.md §2.3, DESIGN.md §4).
- **표시 형태**:
  - 전면 오버레이 배너:
    - `"Allnight는 1024px 이상의 데스크톱 환경에 최적화된 지도 서비스입니다."`
    - `"더 큰 화면의 브라우저에서 접속하시거나 창 크기를 넓혀주세요."`

## 3. 완료 조건 (Acceptance Criteria)

1. [ ] 일반 회원이 `/admin` 접근 시 403 화면이 표시되고 메인 지도 링크가 제공된다.
2. [ ] 유효하지 않은 `/place/:placeId` 접근 시 지도 바탕을 유지한 채 왼쪽 패널에 '장소 없음'이 표시된다.
3. [ ] 검색 결과가 없을 때 필터 초기화 버튼과 신규 제보 링크가 정상 노출된다.
4. [ ] 제보 작성 중 이탈 시 확인 대화상자가 뜨고 계속 작성 또는 나가기가 동작한다.
5. [ ] 1024px 미만 해상도 접근 시 최적화 안내 오버레이가 표시된다.
6. [ ] 비회원의 리뷰 작성 클릭 시 로그인 모달이 뜨고, 로그인 후 해당 장소의 리뷰 작성 단계로 정확히 복귀한다.
