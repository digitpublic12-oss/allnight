# 페이지 명세: 관리자 장소 관리 목록 (`/admin/places`)

> 경로: `/admin/places`  
> 상태: [MVP] 1차 구현 대상  
> 대상 플랫폼: 데스크톱 웹  
> 레이아웃: 관리자 셸 (사이드바 + 상단 검색/필터 바 + 데이터 테이블)

---

## 1. 페이지 목적 및 접근 권한

### 1.1 페이지 목적
- DB에 등록된 전국의 모든 장소를 목록으로 조회하고, 카테고리·지역·검증 상태별로 검색·필터링한다.
- 장소별 별도 편집 화면으로 진입하거나, 관리자 현장 실확인일 갱신 및 소프트 삭제를 관리한다.

### 1.2 접근 권한
- **관리자 전용 (`profiles.role = 'admin'`)**
- 관리자 권한 미보유 시 접근 차단 (403 Forbidden).

---

## 2. UI 구성과 사용자 동작

### 2.1 상단 검색 및 필터 영역
1. **검색창**: 장소명, 주소, 도로명 키워드 검색.
2. **카테고리 필터**: 전체 또는 8개 대분류 중 선택.
3. **지역 필터**: 시·도(예: 서울특별시, 경기도 등) 드롭다운.
4. **검증 상태 필터**: 전체 / 확인됨(`verified`) / 확인 필요(`needs_check`) / 미확인(`unverified`).
5. **정보 오래됨 필터**: 체크박스 (`[ ] 30일 초과 미확인 장소만 보기`).
6. **삭제된 장소 포함 필터**: `[ ] 삭제된 장소 포함`.
7. **우측 액션 버튼**:
   - **[+ 장소 신규 등록]**: `/admin/places/new`로 이동.
   - **[CSV 일괄 등록]**: 대량 임포트 모달 오픈.

### 2.2 장소 데이터 테이블 (DESIGN.md §11)
- 정보 밀도가 높은 컴팩트 테이블 (본문 12~14px, 숫자 tabular numerals):
  - **장소명**: 클릭 시 해당 장소 편집 화면(`/admin/places/:placeId/edit`)으로 이동. 대표 사진 유무 아이콘 표시.
  - **카테고리**: 카테고리명 뱃지.
  - **주소 / 지역**: 시·군·구 및 상세 주소 (말줄임 처리, 툴팁 제공).
  - **검증 상태**: `확인됨(verified)` / `확인 필요(needs_check)` / `미확인(unverified)`.
  - **마지막 확인일**: `YYYY-MM-DD` 표기. 30일 초과 시 앰버 뱃지 표시.
  - **미해결 주의**: 미처리 수정 제보 있음 / 영업 불일치 제보 있음 아이콘.
  - **등록일**: 생성일자.
  - **액션**:
    - **[편집]**: `/admin/places/:placeId/edit` 이동.
    - **[실확인 갱신]**: 관리자가 유선/현장 확인 후 '확인됨' 및 확인일을 즉시 갱신하는 모달 오픈.
    - **[삭제]**: 소프트 삭제 처리.

### 2.3 주요 인터랙션 모달
1. **[실확인 갱신] 모달**:
   - 확인 근거 입력: 확인 방법(유선 통화, 공식 SNS/웹사이트, 현장 방문 등 선택) 및 확인 메모.
   - [확인 완료] 클릭 시: `places.verification_status = 'verified'`, `places.last_verified_at = now()`, `verification_history` 행 추가.
2. **[장소 삭제] 확인 모달**:
   - `"정말 이 장소를 삭제(비공개) 처리하시겠습니까? 연결된 리뷰 및 이력은 보존되며 공개 검색에서 숨겨집니다."`
   - 확인 시 `places.deleted_at = now()` 설정.

## 3. DB 연동 및 API

### 3.1 호출 API
- `GET /api/admin/places`
  - 쿼리 파라미터: `q`, `categoryId`, `province`, `verificationStatus`, `isOlderThan30Days`, `includeDeleted`, `page`, `limit`.
- `POST /api/admin/places/:placeId/verify`
  - 관리자 실확인 처리 및 이력 기록.
- `DELETE /api/admin/places/:placeId`
  - 장소 소프트 삭제.

### 3.2 참조 테이블 및 보안
- `places`, `categories`, `verification_history`, `submissions`, `opening_reports`
- RLS: 관리자 권한 세션만 SELECT/UPDATE/DELETE 수행 가능.

---

## 4. 예외 상태 (Error States)

### 4.1 조건에 맞는 장소 없음
- 검색 결과가 0건일 때: `"검색 조건에 맞는 장소가 없습니다. 검색어를 변경하거나 필터를 초기화하세요."` 테이블 빈 상태 표시.

### 4.2 삭제 실패
- 외래키 제약조건 위반 또는 권한 부족으로 삭제 실패 시 오류 토스트 표시.

---

## 5. 완료 조건 (Acceptance Criteria)

1. [ ] 관리자 장소 목록 테이블에 등록된 장소들의 핵심 정보가 페이징과 함께 정상 출력된다.
2. [ ] 키워드 검색, 카테고리, 지역, 검증 상태, 30일 초과 필터가 정확히 동작한다.
3. [ ] [편집] 클릭 시 해당 장소의 별도 편집 화면으로 정상 전환된다.
4. [ ] [실확인 갱신] 시 `verification_history`가 기록되고 마지막 확인일이 갱신된다.
5. [ ] [삭제] 실행 시 `deleted_at`이 설정되어 공개 검색 결과에서 즉시 제외된다.
